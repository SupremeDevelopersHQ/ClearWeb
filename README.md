# 🔓 CopyFreedom

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Buy Me A Coffee](https://img.shields.io/badge/Buy%20Me%20A%20Coffee-techieajju-orange?logo=buy-me-a-coffee)](https://buymeacoffee.com/techieajju)

**CopyFreedom** is a lightweight, privacy-friendly, open-source browser extension that re-enables copy, paste, text selection, and right-click context menus on websites that block them.

---

## ✨ Features

- 📋 **Re-enables Copy & Paste**: Bypass oncopy and onpaste restrictions.
- 🖱️ **Unlocks Right-Click Menu**: Restore native browser context menus.
- ✍️ **Forces Text Selection**: Overrides CSS user-select locks.
- 🔕 **Off by Default**: Does not interfere until you toggle it.
- 🌐 **Per-Site or Global Mode**: Toggle per domain or enable everywhere.
- 🔒 **100% Privacy Friendly**: Zero analytics, runs locally.
- ⚡ **Cross-Browser**: Compatible with Chrome, Edge, Brave, and Firefox.
