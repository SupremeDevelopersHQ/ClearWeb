# 🔓 SupremeCopy+ Allow Right Click & Select

Are you tired of websites blocking you from copying text, right-clicking, or highlighting content? **SupremeCopy+** is the ultimate tool to bypass frustrating restrictions and give you full control over your browsing experience.

## 🚀 Version 2.0 Features
* **Enable Right-Click:** Restores the native context menu anywhere.
* **Allow Text Selection:** Bypasses CSS locks so you can highlight text again.
* **🎯 Sniper Mode:** Click the crosshair and hover over any annoying popup, cookie banner, or invisible glass shield to instantly delete it from the page!
* **📖 Zen Mode (Reader Mode):** Instantly deletes sidebars, ads, and videos, pulling the pure article text into a clean, full-screen reading overlay.
* **📝 Copy as Markdown:** Automatically converts highlighted web text into perfect Markdown format.
* **📋 Copy as Plain Text:** Automatically strips messy HTML formatting when you press `Ctrl+C`.
* **Global Mode:** Keep the unblocker permanently active on all sites.

## 🔒 Privacy First (Zero Data Collection)
We believe your data is yours. SupremeCopy+ runs **100% locally** on your computer. It does not track your browsing history, does not collect analytics, and does not transmit any data over the internet.

## ⚠️ Known Limitations
SupremeCopy+ works perfectly on 95% of the internet, but has a few physical limits:
* **Images & Scans:** The extension cannot extract text from flat pictures or scanned book pages (like Google Books). It only unblocks real web text.
* **Google Docs:** It cannot select text inside complex canvas-based web editors like Google Docs.
* **Web Games & Apps:** Because SupremeCopy+ aggressively protects your `Ctrl+C` keyboard shortcut, we recommend keeping it **OFF** when playing browser games or using web-based photo/video editors.
